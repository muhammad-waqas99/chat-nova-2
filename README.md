A full-stack real-time chat application built with Next.js and TypeScript.

## Planned Features

- User authentication
- One-to-one conversations
- Group chat
- Real-time messaging
- Conversation sidebar
- Message history
- Read receipts
- Image and file sharing
- Voice notes
- Voice calls
- Video calls
- End-to-end encryption
- Responsive chat interface

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- Axios

### Backend

- Next.js API Routes
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

### Real-Time & Communication

- Socket.IO
- WebRTC

### Storage

- ImageKit

## Project Status

Chat Nova 2 is being developed incrementally, starting with the core authentication, conversation, and messaging system before adding real-time communication and advanced features.
